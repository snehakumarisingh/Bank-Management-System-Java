#  Bank Management System

A console-based banking application built using **Java, MySQL, and JDBC** to manage bank accounts and transactions.

## Features
- Customer registration and login
- Open and manage bank accounts
- Deposit, withdraw, and transfer money
- Check balance and transaction history
- Admin can manage customers and accounts

## Technologies
- Java
- MySQL
- JDBC
- OOP Concepts

## How to Run
1. Set up the MySQL database.
2. Configure database credentials in `DBConnection.java`.
3. Add the MySQL JDBC driver.
4. Run `Main.java`.

## What I Learned
Java OOP, database connectivity, SQL queries, and exception handling.
